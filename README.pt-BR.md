Portfólio profissional bilíngue de André Narcizo, Desenvolvedor Full Stack na Sysout Tecnologia.
O site apresenta experiência profissional verificada, projetos de engenharia selecionados, stack
técnica, formação e informações de contato direcionadas a recrutadores.

## Destaques

- Conteúdo em português e inglês com seleção persistente de idioma
- Linha do tempo profissional baseada no currículo atual
- Curadoria de projetos full-stack, SaaS, APIs, mobile e arquitetura
- Interface responsiva com temas claro e escuro
- Navegação acessível e suporte à redução de movimento
- SEO e metadados sociais orientados a recrutadores

## Stack tecnológica

| Camada | Tecnologias |
|---|---|
| Frontend | React 19, TypeScript 5.9, Vite 7 |
| Interface | CSS Custom Properties, Framer Motion, Lucide React |
| Qualidade | ESLint, build TypeScript estrito |
| Entrega | Implantação contínua no Netlify |

## Desenvolvimento local

```bash
git clone https://github.com/DevAndreNarcizo/portifolio-andre-react.git
cd portifolio-andre-react
npm install
npm run dev
```

## Validação

```bash
npm run lint
npm run build
```
